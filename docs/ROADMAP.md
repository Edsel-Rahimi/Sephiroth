## ⚠️ بدهی‌ها و محدودیت‌های شناخته‌شده (هیچ‌کدام بلوکر نیستند)

- ربات تلگرام در این نمونه **تنظیم نشده**: `mode=console`، بدون توکن، ۰ کاربر/سفارش — با یک توکن واقعی + `adminChatIds` زنده می‌شود (0.1).
- دیسکورد: به توکن + فعال‌بودن MESSAGE_CONTENT در Developer Portal نیاز دارد.
- AmneziaWG: همه‌چیز جز دیمِنِ OS آماده است؛ روی سرور واقعی با `apt install amneziawg` زنده می‌شود (محدودیت سندباکس، نه کد).
- `sidecarAwgBin` در API ست می‌شود ولی فیلد UI‌اش در پاسِ بعدی تنظیمات می‌نشیند.
- درگاه پرداخت ریسلر و اتوماسیون ربات: ✅ از v2.8 ذخیرهٔ واقعی دارند (با ماسک‌کردن اسرار).
